Kevin Dayno's git workflow skills.

## Install

```
/plugin install git-tools@kdayno
```

## Skills

| Skill | What |
|---|---|
| `git-commit` | Create Conventional Commits — analyzes the diff to pick type/scope, stages logically, and writes the message. Vendored from [`github/awesome-copilot`](https://github.com/github/awesome-copilot) (see its `.source.yml`). |
